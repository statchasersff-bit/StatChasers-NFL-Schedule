# Build a Premium StatChasers 2026 NFL Schedule Tool

I want you to build a polished, production-ready **2026 NFL Schedule** tool for StatChasers.

This should NOT look like a generic sports schedule, basic HTML table, or NFL.com clone.

The goal is to create a premium interactive schedule experience that feels like a native StatChasers fantasy football tool.

---

# 1. PURPOSE

Build a tool where users can quickly:

* View the complete 2026 NFL schedule
* Browse by week
* Filter by NFL team
* See bye weeks
* See dates and kickoff times
* See TV/network information when available
* Identify primetime games
* Identify international/holiday/special games
* View an individual team's complete schedule
* Quickly understand home vs. away
* See completed scores once games begin
* Navigate between weeks extremely quickly
* Use the schedule easily on desktop and mobile

This should ultimately be more useful to a fantasy football player than a standard NFL schedule page.

---

# 3. DATA

We need the REAL 2026 NFL schedule.

Do not hardcode fake schedules or placeholder matchups.

Preferred data architecture:

### Primary schedule source

Use machine-readable NFL schedule data from nflverse.

nflverse maintains NFL game/schedule data and is much easier to consume programmatically than scraping website HTML.

Fetch the data SERVER-SIDE where possible.

Filter it to:

```text
season = 2026
game_type = REG
```

The application should then normalize the data into something like:

```js
{
  id,
  season,
  week,
  date,
  time,
  homeTeam,
  awayTeam,
  homeScore,
  awayScore,
  status,
  network,
  stadium,
  location,
  international,
  primetime,
  divisionGame
}
```

Cache schedule data so we are not downloading an external file every time a user opens the page.

Schedule data does not need to refresh constantly.

A cache lasting several hours is fine before the regular season.

During the season, scores/status data can be refreshed more frequently if we later connect a live-data source.

### Validation

Use the official NFL schedule as the authoritative reference if there is ever a discrepancy.

IMPORTANT:

Weeks 16-18 can contain games whose exact dates/times/networks are determined later because of NFL flexible scheduling.

The UI needs to support:

```text
TBD
```

instead of assuming every game has a final kickoff time.

Never display a made-up kickoff time.
